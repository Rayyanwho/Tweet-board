# 🚀 Pulse

A modern social media web application built with **Django** that allows users to create, edit, and manage posts with image uploads through a clean and responsive interface.

---

## ✨ Features

* 🔐 User registration and authentication
* 📝 Create, edit, and delete your own posts
* 🖼️ Image upload support
* 👤 User-specific authorization (users can only edit/delete their own posts)
* 📱 Responsive user interface
* ⚡ Built with Django's authentication system and ORM

---

## 🛠️ Tech Stack

* Python
* Django
* HTML5
* CSS3
* Bootstrap
* SQLite

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Rayyanwho/Tweet-board.git
```

Navigate into the project:

```bash
cd Tweet-board/chaiheadq
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it:

**Windows**

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r ../requirements.txt
```

Apply migrations:

```bash
python manage.py migrate
```

Run the development server:

```bash
python manage.py runserver
```

Visit:

```text
http://127.0.0.1:8000/
```
